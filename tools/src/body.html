[[NASA C-MAPSS: vida útil restante de motores :: NASA C-MAPSS: remaining useful life of engines]]

[[O modelo estima quantos ciclos ainda restam a um motor turbofan a partir de 21 sensores. O XGBoost final erra 10,98 ciclos (RMSE) no teste, em dados simulados. :: The model estimates how many cycles a turbofan engine has left from 21 sensors. The final XGBoost is off by 10.98 cycles (RMSE) on the test set, on simulated data.]]

[[Repositório cmapss-rul :: cmapss-rul repository]]

  • [[Regressão linear :: Linear regression]][[20,82 :: 20.82]]
  • Random Forest[[17,16 :: 17.16]]
  • LSTM[[13,83 :: 13.83]]
  • GRU[[13,72 :: 13.72]]
  • [[XGBoost final :: Final XGBoost]][[10,98 :: 10.98]]

[[RMSE em ciclos, menor é melhor. Dados simulados da NASA, FD001, uma condição de operação; último ciclo de cada um dos 100 motores de teste. XGBoost: 10,98 no teste e 11,15 ± 0,10 na média de sementes. :: RMSE in cycles, lower is better. Simulated NASA data, FD001, one operating condition; last cycle of each of the 100 test engines. XGBoost: 10.98 on the test set and 11.15 ± 0.10 averaged over seeds.]]

  • [[Dados simulados :: Simulated data]][[Uma única condição de operação. Isto não é validação em motores reais. :: A single operating condition. This is not validation on real engines.]]
  • [[GRU e LSTM não superaram :: GRU and LSTM did not beat it]][[Com 100 motores de treino, a rede não superou as variáveis feitas à mão. :: With 100 training engines, the network did not beat the hand-built features.]]
  • [[A regressão à média continua :: Regression to the mean remains]][[50% dos motores ainda têm a vida útil superestimada, o erro mais caro em manutenção. :: 50% of the engines still have their remaining life overestimated, the costliest error in maintenance.]]
